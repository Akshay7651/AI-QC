=====================================================================================
 AI-QC  -  COMPLETE SETUP AND RUN GUIDE (Windows PC, offline, no API key, CPU only)
 From a fresh PC to the finished QC Excel.  Follow the steps in order.
=====================================================================================

WHAT YOU GET
  The program reads the signed Proforma-3 form and the field photos of every docket in your Excel and writes, per row,
  a simple remark and a verdict (OK / Review / Reject-evidence / Manual-check) into a new Excel.  It also shows a live
  dashboard in the browser while it works.  Everything runs on your own PC.

YOUR FOLDERS (this guide uses these; change the letters if yours differ)
  Project folder   D:\All_Application\AI-QC
  Input Excel      D:\All_Application\AI-QC\Input\Data.xlsx
  Results          D:\All_Application\AI-QC\results\
  Downloaded files D:\All_Application\AI-QC\media\<docket>\form\   and   ...\media\


=====================================================================================
 PART A - ONE-TIME SETUP  (about 30 minutes)
=====================================================================================

A1. Install Python 3.11
    - Download from python.org.  On the first installer screen TICK "Add python.exe to PATH".
    - Check: open PowerShell and type   python --version     (must show 3.11 or 3.12)

A2. Install Tesseract (reads the printed Hindi / English text)
    - Download the Windows installer: github.com/UB-Mannheim/tesseract/wiki
    - Install in the default folder  C:\Program Files\Tesseract-OCR
    - On the "Choose components" screen open "Additional language data" and TICK  Hindi.
    - Add it to PATH:  Start menu > "Edit the system environment variables" > Environment Variables >
      select "Path" > Edit > New > paste   C:\Program Files\Tesseract-OCR   > OK, OK.
    - CLOSE PowerShell and open a new one.  Check:   tesseract --list-langs     (must list  eng  and  hin)

A3. Install Git
    - Download from git-scm.com and install with the default options.

A4. Get the project (only if you do not have the folder yet)
    Open PowerShell and run:
        cd D:\All_Application
        git clone https://github.com/akshay7651/ai-qc.git AI-QC
        cd AI-QC
        git checkout claude/new-session-qd93xp
    (If your folder was made from a downloaded ZIP and "git pull" says "not a git repository", run these 4 lines inside it:
        git init
        git remote add origin https://github.com/akshay7651/ai-qc.git
        git fetch origin claude/new-session-qd93xp
        git checkout -f -B claude/new-session-qd93xp FETCH_HEAD )

A5. Create the Python environment and install the packages
    In PowerShell, inside D:\All_Application\AI-QC :
        python -m venv .venv
        .\.venv\Scripts\python.exe -m pip install --upgrade pip
        .\.venv\Scripts\python.exe -m pip install -r requirements.txt
    (pandas is limited to version 2.x on purpose: pandas 3 is blocked by Windows "Smart App Control" on some PCs.)
    From now on ALWAYS use   .\.venv\Scripts\python.exe   to run things (even if another environment such as conda is active).

A6. If Windows blocks a file ("An Application Control policy has blocked this file", a .pyd error)
    Start > Windows Security > App & browser control > Smart App Control settings > set to  OFF.
    Then run the pip install again.

A7. Check that everything is ready
        .\.venv\Scripts\python.exe tools\selfcheck.py
    The last line must say   RESULT: READY.   If a line says FAIL it tells you what is missing (for example "Hindi language data").

A8. (Optional) Run the self-tests
        .\.venv\Scripts\python.exe -m pytest -q tests
    All tests should pass (a few skipped is normal).


=====================================================================================
 PART B - PUT YOUR EXCEL IN PLACE
=====================================================================================

B1. Copy your CLAP export to   D:\All_Application\AI-QC\Input\Data.xlsx
    The Excel needs the usual app columns: docket_id, farmer_name, village, surveyor_name, latitude, longitude,
    affected_area_pct, crop_loss_pct, pdf_url (the signed form link), media_urls (the photo links), crop_name ...
    Other column names are recognised automatically.

B2. Forms and photos:  you do NOT need to download them yourself.
    The program downloads them first (see Part C).  If you already have them in a folder, add  --local-media <folder>
    to the commands below.  Accepted layouts:
        <folder>\<docket>\form\any.jpg|pdf   and   <folder>\<docket>\media\photo1.jpg ...
        or one flat folder:  <docket>.jpg (form), <docket>_1.jpg, <docket>_2.jpg (photos)
        or one ZIP per docket.


=====================================================================================
 PART C - RUN THE QC
=====================================================================================

Always run from the project folder:   cd D:\All_Application\AI-QC

C1. TEST on the first 100 rows (do this first)
        .\.venv\Scripts\python.exe run_qc.py --input Input\Data.xlsx --limit 100 --agents 6 --output results\test100.xlsx

    What happens:
      Step 1  It downloads the forms and photos of the 100 rows into  media\  (12 downloads at the same time).
              You see:  downloaded 40/100 rows ...   QC starts only after the download finishes.
              Files already downloaded are skipped, so running again is fast.
      Step 2  The robots (agents) read the forms and photos and write the remarks.
    Open the live dashboard in your browser:   http://localhost:8765
      - small robots show what each agent is doing (reading the form / checking photos / downloading)
      - the table below shows every finished row with its verdict and remark, newest first
      - "Download as Excel (CSV)" saves the table as it is right now
    The result is saved in   results\test100.xlsx   (autosaved every minute while running).

C2. See how long the full run will take (nothing is processed)
        .\.venv\Scripts\python.exe run_qc.py --input Input\Data.xlsx --agents 8 --dry-run
    Use --agents = number of CPU cores (Task Manager > Performance > CPU > Cores).  Never more.
    Your PC has 8 cores: use 6 while you also work on the PC, 8 when you leave it alone.

C3. FULL RUN (leave it running; the PC must not go to sleep)
        .\.venv\Scripts\python.exe run_qc.py --input Input\Data.xlsx --agents 8 --chunk-rows 20000 --output results\all.xlsx
    - Result: results\all_part001.xlsx, all_part002.xlsx ... (20,000 rows each) and one merged results\all.csv
    - For a smaller file (up to ~40,000 rows) you can leave out --chunk-rows and get a single Excel.
    - Disk space: each docket needs about 1-3 MB.  If the disk is small add   --discard-media   (deletes each docket's
      files right after it is checked).

C4. If it stops (power cut, crash, Ctrl+C, PC went to sleep)
    Run EXACTLY THE SAME command again and add   --resume
    It continues where it stopped and never repeats finished rows.

C5. Run on several PCs or on several days
        --offset 0 --limit 40000        then        --offset 40000 --limit 40000     ...
    Join the parts later:   .\.venv\Scripts\python.exe tools\merge_qc.py results\batch*.csv --output ALL.csv


=====================================================================================
 PART D - READ THE RESULT EXCEL
=====================================================================================

All your original columns are kept; the AI columns are added at the right.

  QC Verdict ........ OK              = nothing wrong found
                      Review          = a person should look (something does not match / is missing / suspicious)
                      Reject-evidence = the evidence is not acceptable (no form link, "photos" are pictures of the paper
                                        form, uploaded paper is not Proforma-3, ...)
                      Manual-check    = the AI could not decide (form not clear enough to read, files could not be downloaded)
  Any Other Remarks . ONE SIMPLE REMARK per row: what is wrong, then FORM / PHOTOS / PLACE facts.  Read this first.
  AI Technical Detail  the longer technical version of the remark (for the technical team only).
  Form No, Affected area% (Form), Crop Loss% (Form), Match/Mismatch .... what the AI read on the form and the comparison
                      with the app.  BLANK means "not clear enough to read" - the AI never guesses.
  Signature columns . farmer / company / primary worker (block officer is not assessed).
  Photo columns ..... photo is the paper form, farmer/person visible in the photos (at least 25% of a body in ANY photo of the
                      docket), photo GPS distance from the app point, date of the photo as stamped on the picture.
  Same_Location_Remark  other surveys within 25 m (same surveyor / other surveyors).
  Risk_Score / Risk_Reasons  review priority 0-100 (a priority, not proof of anything).

HOW SURE IS IT?  The AI only states a value when it is confident (target: every stated value at least 95% right).
When it is not sure it says "not readable" and the row goes to Manual-check.  More training data = fewer Manual-check rows.

=====================================================================================
 PART F - MAKE THE AI BETTER (retraining)  - optional, do it when you have time
=====================================================================================

F1. Install the training packages once:
        .\.venv\Scripts\python.exe -m pip install -r requirements-train.txt

F2. Train from your own CLAP export (uses the values the surveyors typed in the app as labels; takes the forms with
    non-zero loss first because that is what the AI reads worst).  Runs for hours - leave it running:
        .\.venv\Scripts\python.exe retrain.py --labels Input\Data.xlsx --app-values --max-rows 3000 --init --steps 4000
    It keeps 10-15% of the rows aside, compares the old and the new model on them and adopts the new one ONLY if it is
    not worse (the old model is backed up in models\backup).

F3. Train from human-checked rows (best quality).  Prepare human_qc.xlsx with columns
    Docket_ID, Signed_Copy_URL, "Affected area% (Form)", "Crop Loss% (Form)" and run:
        .\.venv\Scripts\python.exe retrain.py --labels human_qc.xlsx --init

F4. After retraining run the 100-row test again and compare the verdict counts.


=====================================================================================
 PART G - PROBLEMS AND FIXES
=====================================================================================
 "tesseract is not recognized"        Add C:\Program Files\Tesseract-OCR to PATH (A2) and open a NEW PowerShell.
 selfcheck says Hindi missing         Run the Tesseract installer again and tick Hindi.
 "git: not a git repository"          Use the 4 lines in A4 (git init ...).
 .pyd / Application Control blocked   Turn Smart App Control OFF (A6), then reinstall packages.
 Dashboard page does not open         Add  --serve-port 8800  (and open http://localhost:8800) or  --no-serve.
 Excel says file is locked            Close the result Excel; the program saves a time-stamped copy and carries on.
 Very slow                            Set --agents to your core count; close other heavy programs; keep the PC awake.
 Downloads fail / many "could not be downloaded"   Check you can open one pmfby.gov.in link in the browser; run the same
                                      command again - missing files are tried again.
 Out of disk space                    Use --discard-media, or point --media-dir to another drive:  --media-dir E:\media
 Anything else                        Copy the exact error text (or a screenshot) and send it to Claude together with
                                      the file docs\STATUS.md.

 More detail: HOW_TO_RUN.md, docs\RUN_GUIDE.md, docs\TRAINING_GUIDE.md, docs\STATUS.md
